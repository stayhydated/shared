# stayhydated-dioxus-core

Generic Dioxus components and visual assets for public repository sites. The
crate includes project landing and portal primitives, metadata, demo cards,
tabs, selects, full-screen demo framing, motion styles, and the shared shader
background.

Use this crate for individual primitives. Use
[`stayhydated-dioxus`](../stayhydated-dioxus/README.md) when a site needs
consumer-owned project configuration, routing, and a complete application
shell.

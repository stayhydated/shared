# stayhydated-dioxus

Configured Dioxus application shells for stayhydated project sites. Consumers
own their identity and destinations through `Project` and `ProjectSite`, then
choose a single-page portal, an embedded-demo portal, or a custom `Routable`
application.

The crate re-exports the common components from `stayhydated-dioxus-core`. See
the
[`use-stayhydated-github-pages`](../../skills/use-stayhydated-github-pages/SKILL.md)
skill for dependency pinning, routing, build assembly, and deployment guidance.
